Loading all 25 tool schemas into every agent step bloats context and causes parameter hallucinations. CheckpointMCP dynamically scores and injects only the Top-3 schemas per step (~340 tokens) while enforcing Read / Stage / Mutate execution gates.

Product Specs & First-Principles Tradeoffs

1. Autonomy vs. User Trust

Instead of binary "full auto" or "ask on every step" (which causes approval fatigue), tools are classified into READ (auto-run), STAGE (create UI draft), and MUTATE (hard async pause for 1-click approval).

2. Fault Tolerance vs. Token Cost

Multi-step agents frequently fail at Step 4/5 due to brittle external APIs. Persisting SQLite checkpoints per step lets users inspect, edit the JSON payload, and resume mid-flight—saving ~42% wasted token spend.

3. Context Breadth vs. Latency

Dumping 25+ MCP schemas into every LLM call adds ~2,870 tokens of noise per step. A lightweight keyword/intent router prunes context to Top-3 tools, cutting latency by 1.57s/step and reducing wrong-tool calls.
